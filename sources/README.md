# Kept source lists

- `okinawa-judan-2018.csv` — the hanshi 10th-dan register (146 names: 56 deceased, 90 living
  at publication) compiled over eight years by Miguel Da Luz and published in *Okinawa Karate
  News* (沖縄空手通信) No. 146, November 2018, Okinawa Media Planning. The article does not
  mark status per individual, so no status column is asserted here. Romaji kept as printed;
  kanji preserved for matching.
